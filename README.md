# Bubble Burst

A meditative bubble-wrap popping playground. Pick an object, unwrap it, and pop every last bubble.

Live: https://rupam.work/bubble-burst/

- Six objects, each wrapped in its own size of bubble wrap
- Fold the sheet's corners, pop single bubbles or drag across a row
- Lo-fi "Popping tape" on the record player
- Share a sheet of calm with a friend

Object images and music generated with [Atlabs](https://atlabs.ai).
